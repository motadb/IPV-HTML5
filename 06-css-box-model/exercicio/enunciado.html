Ficha 06 — Página de Perfil com Layout

Box Model, display, margin, padding e position

Objetivos

  • Aplicar o box model: margin, padding, border
  • Usar box-sizing: border-box
  • Controlar display: block, inline-block e none
  • Usar position: relative, absolute e fixed
  • Criar um layout de página com largura máxima e centrado

Enunciado

Cria uma página de perfil de estudante chamada perfil.html com um ficheiro CSS css/perfil.css.

Layout a implementar

Estrutura visual esperada
┌─────────────────────────────────────────────────┐
│  NAVBAR (fixo no topo, fundo escuro, 60px)      │
└─────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────┐
│                                                 │
│  HERO (fundo colorido, texto centrado, 200px)   │
│                                                 │
└─────────────────────────────────────────────────┘
┌──────────────────────────── max-width: 800px ───┐
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │  CARD (fundo branco, sombra, padding)   │   │
│  │  Nome, curso, avatar circular           │   │
│  └─────────────────────────────────────────┘   │
│                                                 │

│                                                 │
│  SECÇÃO "Sobre mim" com border-left colorida   │
│                                                 │
└─────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────┐
│  FOOTER (fundo escuro, text center)             │
└─────────────────────────────────────────────────┘

Requisitos CSS detalhados

  • Reset com box-sizing: border-box e margin/padding a 0.
  • Navbar fixa: position: fixed; top: 0; width: 100%; com z-index.
  • O body deve ter padding-top suficiente para não ficar atrás da navbar.
  • Hero: fundo em gradiente ou cor sólida, min-height 200px, texto centrado, padding 3rem.
  • Container central: max-width 800px, margin 0 auto, padding 0 1.5rem.
  • Card de perfil: fundo branco, padding 2rem, border-radius 12px, box-shadow.
  • Avatar: imagem 100×100px com border-radius 50% (círculo).
  • Badges de competências: display: inline-block, padding 0.25rem 0.75rem, border-radius 999px, cor de fundo e cor de texto.
  • Secção "Sobre mim": border-left de 4px com cor de destaque, padding-left 1rem.
