6.1 O modelo de caixa (Box Model)

Todo o elemento HTML é tratado pelo browser como uma caixa retangular composta por quatro camadas, de dentro para fora:

Diagrama do Box Model
┌─────────────────────────────────────────────┐
│                  MARGIN                      │  ← espaço fora da caixa
│  ┌───────────────────────────────────────┐  │
│  │               BORDER                  │  │  ← borda visível
│  │  ┌─────────────────────────────────┐  │  │
│  │  │             PADDING             │  │  │  ← espaço interior
│  │  │  ┌───────────────────────────┐  │  │  │
│  │  │  │         CONTENT           │  │  │  │  ← conteúdo real
│  │  │  └───────────────────────────┘  │  │  │
│  │  └─────────────────────────────────┘  │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
  • Content — o conteúdo do elemento (texto, imagem, etc.)
  • Padding — espaço interior entre o conteúdo e a borda
  • Border — a borda visível do elemento
  • Margin — espaço exterior entre este elemento e os outros

6.2 Margin e Padding

Ambos podem ser definidos para os quatro lados separadamente ou com atalhos: 

/* Atalhos */

.elemento {
  /* 1 valor: todos os lados */
  margin: 1rem;

  /* 2 valores: cima/baixo  esquerda/direita */
  margin: 1rem 2rem;

  /* 3 valores: cima  esquerda/direita  baixo */
  margin: 1rem 2rem 0.5rem;

  /* 4 valores: cima  direita  baixo  esquerda (sentido horário) */
  margin: 1rem 2rem 0.5rem 0;

  /* Lados individuais */
  margin-top: 1rem;
  margin-right: 2rem;
  margin-bottom: 1rem;
  margin-left: 0;
}

/* Centrar horizontalmente um bloco */
.centrado {
  width: 800px;
  margin: 0 auto;
}
Colapso de margens (margin collapse) Quando dois elementos de bloco estão um sobre o outro, as suas margens verticais "colapsam" — em vez de somarem, prevalece a maior. margin-bottom: 2rem + margin-top: 1rem = 2rem (não 3rem). Isso não acontece com padding.

6.3 Border

.cartao {
  /* Atalho: espessura estilo cor */
  border: 2px solid #e2e8f0;

  /* Lados individuais */
  border-top: 4px solid #2563eb;
  border-bottom: 1px dashed #ccc;

  /* Estilo: none | solid | dashed | dotted | double */
  border-style: solid;
  border-width: 1px;
  border-color: #ccc;

  /* Cantos arredondados */
  border-radius: 8px;

  /* Círculo (funciona em elemento quadrado) */
  border-radius: 50%;

  /* Sombra da caixa */
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}

6.4 box-sizing

Define o que é incluído no width e height de um elemento:

  • content-box (por defeito): width = só o conteúdo. O padding e a borda adicionam ao tamanho total.
  • border-box (recomendado): width = conteúdo + padding + borda. O tamanho total é exatamente o que defines. 
/* Reset recomendado — inclui em todos os projetos */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* Exemplo da diferença: */
.caixa {
  width: 200px;
  padding: 20px;
  border: 2px solid #000;
}
/* content-box: largura real = 200 + 20+20 + 2+2 = 244px */
/* border-box:  largura real = 200px (sempre)             */

6.5 A propriedade display

Controla como o elemento participa no fluxo da página:

ValorComportamento
block Ocupa a largura toda. Começa em nova linha. Aceita width/height.
inline Flui com o texto. Não aceita width/height. Não quebra linha.
inline-block Flui com o texto mas aceita width/height e padding/margin verticais.
none Remove completamente o elemento — como se não existisse (não ocupa espaço).
flex Ativa o Flexbox no contentor. (Cap. 07)
grid Ativa o Grid no contentor. (Cap. 08) 
/* Esconder/mostrar elementos */
.menu-mobile { display: none; }   /* esconde */
.menu-mobile.ativo { display: block; } /* mostra */

/* Botões lado a lado com inline-block */
.btn {
  display: inline-block;
  padding: 0.5rem 1rem;
  border-radius: 4px;
}

6.6 Width e Height

.contentor {
  width: 800px;         /* largura fixa */
  max-width: 100%;     /* nunca ultrapassa o pai */
  min-width: 300px;    /* mínimo de 300px */

  height: 400px;        /* altura fixa (evitar quando possível) */
  min-height: 200px;  /* mínimo de altura */
}

/* Layout centrado responsivo (padrão muito comum) */
.pagina {
  max-width: 1200px;
  width: 100%;
  margin: 0 auto;
  padding: 0 1.5rem;
}

6.7 Overflow

Define o que acontece quando o conteúdo ultrapassa o tamanho do elemento:

.caixa {
  overflow: visible; /* por defeito: conteúdo transborda */
  overflow: hidden;  /* corta o excesso */
  overflow: scroll;  /* barra de scroll sempre */
  overflow: auto;    /* barra de scroll só se necessário */

  /* Por eixo */
  overflow-x: hidden;
  overflow-y: auto;
}

6.8 Posicionamento

ValorComportamento
static Padrão. Elemento no fluxo normal. top/left/etc. não têm efeito.
relative Desloca o elemento em relação à sua posição normal. Não sai do fluxo.
absolute Remove do fluxo. Posiciona em relação ao ancestral com position não-static.
fixed Remove do fluxo. Posiciona em relação à janela. Não rola com a página.
sticky Normal até chegar ao limite definido, depois fica fixo. 
/* Navbar fixa no topo */
nav {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  z-index: 100;    /* por cima dos outros elementos */
}

/* Centrar um elemento filho absolute */
.pai { position: relative; }
.filho {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

/* Header sticky */
header {
  position: sticky;
  top: 0;
}
