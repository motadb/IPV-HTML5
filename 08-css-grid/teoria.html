8.1 Conceito de CSS Grid

O CSS Grid Layout é um sistema de layout a duas dimensões — linhas e colunas em simultâneo. Enquanto o Flexbox é ideal para componentes lineares (uma barra de nav, um conjunto de botões), o Grid é ideal para layouts de página completos. 

<!-- HTML -->
<div class="grid">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</div>
/* CSS */
.grid {
  display: grid;
  grid-template-columns: 200px 200px 200px;  /* 3 colunas de 200px */
}

8.2 Colunas e linhas

.grid {
  display: grid;

  /* 3 colunas de tamanhos fixos */
  grid-template-columns: 200px 300px 200px;

  /* 3 colunas iguais com fr */
  grid-template-columns: 1fr 1fr 1fr;

  /* Atalho com repeat() */
  grid-template-columns: repeat(3, 1fr);

  /* Coluna lateral + conteúdo */
  grid-template-columns: 250px 1fr;

  /* Definir alturas das linhas */
  grid-template-rows: 80px 1fr 60px;
}

8.3 A unidade fr (fraction)

fr representa uma fração do espaço disponível no container, depois de deduzir colunas fixas. 

/* Container de 900px */
.grid {
  display: grid;

  /* 3 colunas iguais (300px cada) */
  grid-template-columns: 1fr 1fr 1fr;

  /* Sidebar 250px + conteúdo com o resto (650px) */
  grid-template-columns: 250px 1fr;

  /* Sidebar pequena + conteúdo grande + aside */
  grid-template-columns: 1fr 2fr 1fr;
  /* = 225px + 450px + 225px (com gap) */
}

8.4 Gap (espaço entre células)

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);

  /* Espaço igual entre linhas e colunas */
  gap: 1.5rem;

  /* Separado: linhas / colunas */
  row-gap: 2rem;
  column-gap: 1rem;

  /* Atalho equivalente */
  gap: 2rem 1rem;
}

8.5 Posicionamento de items

Podes controlar exatamente onde cada item começa e termina, usando números de linha do grid: 

/* Grid de 3 colunas */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Item que ocupa as 3 colunas */
.item-largo {
  grid-column: 1 / 4;   /* da linha 1 à linha 4 */
  /* equivalente a: */
  grid-column: 1 / -1;  /* da primeira à última */
  /* ou com span: */
  grid-column: span 3;   /* ocupa 3 colunas */
}

/* Item que ocupa 2 linhas */
.item-alto {
  grid-row: span 2;
}

/* Posição específica */
.destaque {
  grid-column: 2 / 4;
  grid-row: 1 / 3;
}

8.6 grid-template-areas

A propriedade mais poderosa do Grid: define o layout como um mapa visual, nomeando cada zona. 

/* HTML */
<div class="pagina">
  <header>Header</header>
  <nav>Nav</nav>
  <main>Conteúdo</main>
  <aside>Aside</aside>
  <footer>Footer</footer>
</div>
/* CSS */
.pagina {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: 80px 1fr 60px;
  min-height: 100vh;
  gap: 1rem;

  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
}

/* Atribuir cada elemento à sua área */
header  { grid-area: header; }
nav     { grid-area: nav; }
main    { grid-area: main; }
aside   { grid-area: aside; }
footer  { grid-area: footer; }
Layout responsivo com areas Em ecrãs pequenos basta redefinir o grid-template-areas num media query: 
@media (max-width: 768px) {
  .pagina {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "nav"
      "main"
      "aside"
      "footer";
  }
}

8.7 Alinhamento

/* Alinhamento dos items dentro da célula */
.grid {
  justify-items: start | center | end | stretch;   /* horizontal */
  align-items: start | center | end | stretch;     /* vertical */
  place-items: center;  /* atalho: align-items justify-items */
}

/* Alinhamento de todo o grid no container */
.grid {
  justify-content: start | center | end | space-between;
  align-content: start | center | end | space-between;
}

/* Sobrepor para um item específico */
.item {
  justify-self: center;
  align-self: end;
}

8.8 Grid responsivo automático

Com repeat(auto-fill, minmax(...)) o grid adapta automaticamente o número de colunas ao espaço disponível — sem media queries! 

/* Cartões responsivos: colunas de mínimo 280px */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 1.5rem;
}
/* → 1 coluna em mobile, 2 em tablet, 3+ em desktop */

/* auto-fill vs auto-fit:
   auto-fill: mantém colunas vazias
   auto-fit:  expande os items para preencher */
.cards {
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
}
