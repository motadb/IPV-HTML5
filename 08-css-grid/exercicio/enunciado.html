Ficha 08 — Layout com CSS Grid

grid-template-areas, fr, auto-fill

Objetivos

  • Criar um layout de página completo com grid-template-areas
  • Usar a unidade fr para distribuição de espaço
  • Posicionar items do grid com grid-column e grid-row
  • Criar uma galeria responsiva com auto-fill e minmax
  • Adaptar o layout para mobile com media query

Enunciado

Cria um site de notícias chamado noticias-grid.html com css/grid.css.

Layout da página (desktop)

grid-template-areas
┌──────────────────────────────────────────────────┐
│             header (col 1-3)                     │
├──────────────────────────────────────────────────┤
│             nav (col 1-3)                        │
├──────────────────────┬──────────────────────┬───┤
│                      │                      │   │
│   artigo-1 (1fr)     │   artigo-2 (1fr)    │ A │
│                      │                      │ S │
├──────────────────────┴──────────────────────┤ I │
│                                             │ D │
│         artigo-destaque (2fr, span 2)       │ E │
│                                             │   │
├──────────────────────────────────────────────┴───┤
│             footer (col 1-3)                     │
└──────────────────────────────────────────────────┘

Requisitos

  • O grid da página usa grid-template-areas com as zonas: header, nav, artigo1, artigo2, destaque, aside, footer.
  • 3 colunas: 1fr 1fr 250px (as duas primeiras para conteúdo, a última para o aside).
  • O artigo de destaque ocupa as primeiras duas colunas: grid-column: span 2.
  • O aside ocupa todas as linhas de conteúdo: grid-row: span 2.
  • Dentro do aside, cria uma secção "Mais notícias" com uma mini-galeria usando repeat(auto-fill, minmax(80px, 1fr)).
  • Media query @media (max-width: 768px): colapsa para layout de 1 coluna, redefine as areas.
