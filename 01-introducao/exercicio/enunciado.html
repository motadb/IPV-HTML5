Ficha 01 — A minha primeira página

Introdução ao HTML5

Objetivos

  • Criar um ficheiro HTML5 válido com estrutura base completa
  • Usar corretamente DOCTYPE, head, body e meta charset
  • Usar títulos h1–h3 em hierarquia semântica correta
  • Escrever parágrafos, usar strong, em e comentários
  • Definir o idioma da página com o atributo lang

Enunciado

Cria uma página HTML que funcione como o teu perfil pessoal. A página deve conter as seguintes secções:

1. Cabeçalho da página

  • Um título principal (<h1>) com o teu nome completo.
  • Um subtítulo (<h2>) com o teu curso e ano.

2. Secção "Sobre mim"

  • Um título (<h2>) com o texto "Sobre mim".
  • Dois ou três parágrafos a descreveres-te. Pelo menos um deve ter uma palavra em <strong> e outra em <em>.

3. Secção "Competências"

  • Um título (<h2>) "Competências técnicas".
  • Um título (<h3>) "Linguagens que estou a aprender".
  • Um parágrafo com pelo menos três linguagens mencionadas.

4. Secção "Curiosidade"

  • Uma curiosidade sobre ti, num parágrafo com <small> para uma nota secundária.

5. Comentários

  • Adiciona pelo menos 2 comentários HTML úteis no código.

Requisitos técnicos

  • Ficheiro chamado perfil.html
  • DOCTYPE correto na primeira linha
  • lang="pt" no elemento html
  • meta charset UTF-8
  • meta viewport
  • Título no separador: "Perfil — [o teu nome]"
  • Estrutura correta de h1 → h2 → h3 (sem saltar níveis)
