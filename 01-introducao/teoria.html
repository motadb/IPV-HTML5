1.1 O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). Não é uma linguagem de programação — é uma linguagem de marcação, o que significa que descreve a estrutura e o conteúdo de uma página web através de etiquetas (chamadas tags).

Pensa no HTML como o esqueleto de uma página web: define o que existe (um título, um parágrafo, uma imagem, um link) mas não define como isso fica visualmente — esse é o papel do CSS.

As três tecnologias da web

TecnologiaPapelAnalogia
HTML Estrutura e conteúdo O esqueleto / paredes de um edifício
CSS Apresentação visual A pintura, decoração e design
JavaScript Comportamento e interatividade A eletricidade, elevadores, automatismos
Nota Neste manual focamo-nos em HTML5 e CSS3. JavaScript será abordado noutro módulo.

1.2 Breve história do HTML

  • 1991 — Tim Berners-Lee cria o HTML 1.0 no CERN para partilhar documentos científicos.
  • 1995 — HTML 2.0: primeira versão normalizada.
  • 1997 — HTML 3.2 e HTML 4.0: tabelas, frames, formulários.
  • 1999 — HTML 4.01: versão estável usada por muito tempo.
  • 2008–2014 — HTML5 em desenvolvimento pelo WHATWG e W3C.
  • 2014 — HTML5 torna-se recomendação oficial do W3C.
  • Hoje — HTML "Living Standard": o WHATWG mantém uma especificação viva em contínua evolução.
Novidades do HTML5 Elementos semânticos (header, nav, article…), vídeo e áudio nativos, formulários melhorados, canvas, geolocalização, armazenamento local.

1.3 Como funciona um browser

Quando abres um ficheiro HTML no browser, acontece o seguinte:

  1. O browser lê o ficheiro de cima para baixo, linha a linha.
  2. Interpreta as tags HTML e constrói uma árvore de objetos (o DOM — Document Object Model).
  3. Aplica os estilos CSS e calcula o layout visual.
  4. Desenha o resultado no ecrã (processo chamado rendering).
Ferramentas de programador Prima F12 em qualquer browser para abrires as DevTools. Na aba Elements (Chrome) ou Inspector (Firefox) podes inspecionar a árvore HTML de qualquer página web.

1.4 Estrutura base de um ficheiro HTML

Todo o ficheiro HTML começa com uma estrutura mínima obrigatória. Cria um ficheiro chamado index.html e escreve o seguinte:

index.html
<!-- Declaração do tipo de documento -->
<!DOCTYPE html>

<html lang="pt">

  <head>
    <!-- Metadados: não aparecem na página -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>O título que aparece no separador</title>
  </head>

  <body>
    <!-- Conteúdo visível da página -->
    <h1>Olá, mundo!</h1>
    <p>Esta é a minha primeira página web.</p>
  </body>

</html>

O que significa cada parte?

LinhaSignificado
<!DOCTYPE html> Informa o browser que o documento é HTML5. Obrigatório na 1.ª linha.
<html lang="pt"> Elemento raiz. O atributo lang declara o idioma (importante para acessibilidade e SEO).
<head> Contém metadados: codificação, título, links para CSS, etc. Nada aqui é visível na página.
<meta charset="UTF-8"> Define a codificação de caracteres. UTF-8 suporta acentos, caracteres especiais e emojis.
<meta name="viewport"> Essencial para páginas responsivas em dispositivos móveis.
<title> Texto que aparece no separador do browser e nos resultados de pesquisa.
<body> Tudo o que está aqui é visível na página: textos, imagens, links, etc.
Atenção O <!DOCTYPE html> não é uma tag HTML — é uma instrução para o browser. Sem ela o browser entra em "quirks mode" e comporta-se de forma imprevisível.

1.5 Primeiros elementos

Anatomia de um elemento HTML

Um elemento HTML é composto por:

<p class="intro">Isto é um parágrafo.</p>

  └─ tag de abertura    conteúdo    tag de fecho
       └─ atributo (nome="valor")

Alguns elementos são vazios (não têm conteúdo nem tag de fecho):

<br>   <!-- quebra de linha -->
<hr>   <!-- linha horizontal -->
<img src="foto.jpg" alt="Descrição">   <!-- imagem -->
<meta charset="UTF-8">   <!-- metadado -->

Títulos (h1 a h6)

Existem seis níveis de títulos. O <h1> é o mais importante (geralmente o título principal da página) e deve existir apenas um por página. 

<h1>Título principal (único por página)</h1>
<h2>Secção principal</h2>
<h3>Subsecção</h3>
<h4>Sub-subsecção</h4>
<h5>Raramente usado</h5>
<h6>Ainda mais raramente usado</h6>
Não uses títulos apenas para tornar o texto maior! Os títulos têm significado semântico e são usados por leitores de ecrã (acessibilidade) e motores de busca (SEO). Usa h1→h2→h3 em hierarquia, sem saltar níveis.

Parágrafos

<p>Isto é um parágrafo de texto. O browser adiciona
automaticamente espaçamento antes e depois.</p>

<p>Este é outro parágrafo separado.</p>
Dica No VS Code, escreve ! e prime Tab para gerar automaticamente a estrutura base de um ficheiro HTML5.

1.6 Comentários em HTML

Comentários são texto que o browser ignora completamente. Servem para deixar notas no código ou desativar temporariamente partes do HTML. 

<!-- Isto é um comentário de uma linha -->

<!--
    Isto é um comentário
    de múltiplas linhas
-->

<p>Este parágrafo é visível.</p>

<!-- <p>Este parágrafo está desativado.</p> -->

1.7 Atributos

Os atributos fornecem informação adicional sobre um elemento. Colocam-se sempre na tag de abertura no formato nome="valor". 

<!-- Atributo src define a fonte da imagem -->
<img src="foto.jpg" alt="Foto da turma">

<!-- Atributo href define o destino do link -->
<a href="pagina2.html">Ir para a página 2</a>

<!-- Atributos id e class identificam elementos -->
<p id="intro" class="destaque">Parágrafo de introdução</p>
AtributoUsoExemplo
id Identificador único na página id="cabecalho"
class Classe reutilizável (CSS/JS) class="destaque"
lang Idioma do elemento lang="en"
title Tooltip ao passar o rato title="Clica aqui"
style CSS inline (evitar) style="color:red"
id vs. class Um id deve ser único na página — só um elemento pode ter aquele id. Uma class pode ser usada em múltiplos elementos. Usa sempre id para identificar um elemento específico e class para grupos de elementos com o mesmo estilo.
