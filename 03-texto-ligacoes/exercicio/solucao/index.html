O que é?

Python é uma linguagem de programação de alto nível, interpretada e de propósito geral, criada com o foco na legibilidade do código e na produtividade do programador. O nome vem do grupo de comédia britânico Monty Python, não da cobra!

História

  1. 1989 — Guido van Rossum começa a desenvolver Python no Natal.
  2. 1991 — Lançamento do Python 0.9.0, a primeira versão pública.
  3. 2000 — Python 2.0 introduz list comprehensions e garbage collection.
  4. 2008 — Python 3.0 lançado com melhorias profundas na linguagem.

Vantagens

  • Sintaxe simples e legível, ideal para iniciantes.
  • Enorme comunidade e ecossistema de bibliotecas.
  • Versátil: web, ciência de dados, IA, automação, jogos.
  • Multiplataforma: funciona em Windows, Mac e Linux.

"O Python é uma linguagem que te deixa concentrar no problema que estás a tentar resolver, em vez da linguagem em si."

— Guido van Rossum, criador do Python
