Ficha 03 — Mini-site de 3 páginas

Texto, listas e hiperligações

Objetivos

  • Criar múltiplas páginas HTML ligadas entre si com caminhos relativos
  • Usar corretamente os elementos de formatação de texto
  • Criar listas ordenadas, não ordenadas e de definições
  • Usar âncoras internas para navegação na página
  • Criar links de email e download

Enunciado

Cria um mini-site sobre uma tecnologia à tua escolha (ex: Python, JavaScript, CSS, Inteligência Artificial, Jogos, etc.). O site deve ter 3 páginas ligadas entre si.

Estrutura de ficheiros

mini-site/
├── index.html      (página inicial)
├── aprender.html   (como aprender)
└── recursos.html   (recursos úteis)

Página 1 — index.html

  • Título h1 com o nome da tecnologia escolhida.
  • Um índice no topo com âncoras para as secções da página (<a href="#secao1">).
  • Secção "O que é?" com id o-que-e: parágrafo com <strong>, <em> e uma abreviatura com <abbr>.
  • Secção "História" com id historia: lista ordenada com 4 marcos históricos.
  • Secção "Vantagens" com id vantagens: lista não ordenada com 4 itens.
  • Uma citação de alguém famoso na área com <blockquote>.
  • Link "Voltar ao topo" (<a href="#">).

Página 2 — aprender.html

  • Navegação com links para as outras duas páginas (usando caminhos relativos).
  • Título h1 "Como aprender [tecnologia]".
  • Lista de definições (<dl>) com 3 conceitos-chave e as suas definições.
  • Lista ordenada com 5 passos para começar.
  • Link de email para "pedir ajuda" (mailto:).

Página 3 — recursos.html

  • Navegação com links para as outras duas páginas.
  • Título h1 "Recursos".
  • Lista não ordenada com 4 recursos (links externos com target="_blank" rel="noopener").
  • Um link de download para um ficheiro PDF fictício (download).
  • Um link de telefone (tel:).
Caminhos relativos Todas as páginas devem estar na mesma pasta. Os links entre elas usam apenas o nome do ficheiro: <a href="aprender.html"> — sem caminhos absolutos!
