3.2 Listas

Lista não ordenada (ul)

Para itens sem ordem específica (marcadores):

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Lista ordenada (ol)

Para itens com ordem importa (numerados):

<ol>
  <li>Criar o ficheiro HTML</li>
  <li>Escrever a estrutura base</li>
  <li>Abrir no browser</li>
</ol>

<!-- Atributos do ol -->
<ol start="5" type="A">  <!-- começa em E -->
  <li>Item E</li>
  <li>Item F</li>
</ol>

Lista de definições (dl)

Para pares termo-definição (glossários, metadados):

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language — linguagem de marcação para páginas web.</dd>

  <dt>CSS</dt>
  <dd>Cascading Style Sheets — linguagem para estilizar páginas HTML.</dd>
</dl>

Listas aninhadas

<ul>
  <li>Tecnologias Web
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Linguagens de Programação
    <ul>
      <li>JavaScript</li>
      <li>Python</li>
    </ul>
  </li>
</ul>

3.3 Hiperligações — o elemento <a>

O elemento <a> (anchor) cria uma hiperligação. O atributo href (hypertext reference) define o destino. 

<!-- Link para outra página do site -->
<a href="sobre.html">Sobre Nós</a>

<!-- Abrir em nova aba -->
<a href="https://www.ipv.pt" target="_blank" rel="noopener">IPV</a>

<!-- Link com título (tooltip) -->
<a href="contacto.html" title="Formulário de contacto">Contacto</a>
AtributoValorEfeito
hrefURL ou caminhoDestino do link
target_blankAbre em nova aba
target_self (padrão)Abre na mesma aba
relnoopener noreferrerSegurança em links externos
downloadnome do ficheiroForça download em vez de abrir
Segurança com target="_blank" Ao abrir um link externo em nova aba, usa sempre rel="noopener noreferrer" para prevenir que a página de destino aceda à janela original.

3.4 Caminhos relativos vs. absolutos

Um caminho (path) é o endereço de um ficheiro. Existem dois tipos:

Caminho absoluto

Contém o endereço completo, começando sempre pelo protocolo ou raiz. Funciona em qualquer contexto mas é rígido — se o site muda de domínio, os links partem. 

<!-- URL completo -->
<a href="https://www.exemplo.pt/paginas/sobre.html">Sobre</a>

<!-- Desde a raiz do site (começa com /) -->
<a href="/paginas/sobre.html">Sobre</a>

Caminho relativo

É relativo à localização do ficheiro HTML atual. Preferível para ficheiros dentro do mesmo projeto.

Imaginando esta estrutura de pastas:

meu-site/
├── index.html
├── sobre.html
├── css/
│   └── estilo.css
├── imagens/
│   └── logo.png
└── paginas/
    ├── contacto.html
    └── portfolio.html

No ficheiro index.html (raiz):

<!-- Mesmo nível -->
<a href="sobre.html">Sobre</a>

<!-- Entrar numa pasta -->
<a href="paginas/contacto.html">Contacto</a>

<!-- Ficheiro CSS numa subpasta -->
<link rel="stylesheet" href="css/estilo.css">

<!-- Imagem numa subpasta -->
<img src="imagens/logo.png" alt="Logótipo">

No ficheiro paginas/contacto.html (dentro da pasta paginas):

<!-- Subir um nível com ../ -->
<a href="../index.html">Início</a>

<!-- Subir e entrar noutra pasta -->
<link rel="stylesheet" href="../css/estilo.css">
<img src="../imagens/logo.png" alt="Logótipo">

<!-- Outro ficheiro na mesma pasta -->
<a href="portfolio.html">Portfolio</a>
Regra de memorização ./ = pasta atual (opcional, podes omitir)
../ = subir um nível
../../ = subir dois níveis
pasta/ficheiro.html = entrar numa pasta

3.5 Âncoras internas

Permitem criar links que apontam para uma secção específica da mesma página (ou de outra). Muito usados em páginas longas (índices de conteúdo). 

<!-- 1. Marca o destino com um id -->
<h2 id="sobre">Sobre Nós</h2>

<!-- 2. Liga para esse id com # -->
<a href="#sobre">Ir para Sobre Nós</a>

<!-- 3. Para outra página + secção -->
<a href="pagina.html#sobre">Sobre na outra página</a>

<!-- 4. Voltar ao topo -->
<a href="#">Voltar ao topo</a>

3.6 Links especiais

<!-- Link de email -->
<a href="mailto:info@exemplo.pt">info@exemplo.pt</a>

<!-- Email com assunto e corpo pré-preenchidos -->
<a href="mailto:info@exemplo.pt?subject=Dúvida&body=Olá,">
  Enviar email
</a>

<!-- Link de telefone (útil em mobile) -->
<a href="tel:+351232000000">+351 232 000 000</a>

<!-- Download de ficheiro -->
<a href="documentos/ficha.pdf" download="ficha-inscricao.pdf">
  Descarregar Ficha
</a>
