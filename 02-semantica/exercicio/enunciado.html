Ficha 02 — Página de Notícias

Estrutura Semântica HTML5

Objetivos

  • Usar os elementos semânticos do HTML5 (header, nav, main, article, aside, footer)
  • Distinguir corretamente article de section
  • Usar div e span apenas quando necessário
  • Atribuir id e class com critério
  • Respeitar a hierarquia bloco/inline

Enunciado

Cria uma página HTML chamada noticias.html que simule a página principal de um jornal online chamado "IPV News".

Estrutura obrigatória

ZonaElementoConteúdo
Cabeçalho <header> Nome do jornal (h1), slogan em parágrafo, data atual com <time>
Navegação <nav> Links: Início, Tecnologia, Desporto, Cultura, Contacto (links com #)
Conteúdo <main> Contém os artigos e o aside
Artigo 1 <article> Notícia de destaque: h2, time, parágrafo longo, um parágrafo com <mark>
Artigo 2 <article> Segunda notícia: h2, time, parágrafo
Artigo 3 <article> Terceira notícia: h2, time, parágrafo
Lateral <aside> h2 "Mais lidas", lista com 4 links de artigos fictícios
Rodapé <footer> © 2024 IPV News · Todos os direitos reservados

Requisitos adicionais

  • Cada <article> deve ter um atributo id único.
  • O <nav> deve usar uma lista <ul> com os links.
  • A data nos artigos deve usar <time datetime="AAAA-MM-DD">.
  • Um dos artigos deve ter uma citação com <blockquote>.
  • Usa o símbolo © com a entidade HTML &copy;.
Sem CSS por agora Nesta ficha não adicionas CSS. O objetivo é a estrutura HTML correta. A página vai parecer "simples" visualmente — isso é normal.
