2.1 O que é semântica?

Semântica significa dar significado ao código. Antes do HTML5 era comum estruturar páginas inteiras apenas com <div>, tornando impossível perceber a função de cada parte sem ler o conteúdo.

Antes (sem semântica):

<div id="cabecalho"> ... </div>
<div id="menu"> ... </div>
<div id="conteudo">
    <div class="artigo"> ... </div>
</div>
<div id="rodape"> ... </div>

Depois (com semântica HTML5):

<header> ... </header>
<nav> ... </nav>
<main>
    <article> ... </article>
</main>
<footer> ... </footer>

As vantagens do HTML semântico são:

  • Acessibilidade: leitores de ecrã (para invisuais) navegam pelos landmarks semânticos.
  • SEO: motores de busca entendem melhor a estrutura do conteúdo.
  • Manutenção: o código é mais fácil de ler e editar.
  • Semântica: o HTML comunica a intenção, não apenas a apresentação.

2.2 Elementos semânticos do HTML5

ElementoSignificadoUso típico
<header> Cabeçalho Logo, nome do site, slogan (do site ou de uma secção)
<nav> Navegação Menu principal, breadcrumbs, paginação
<main> Conteúdo principal Conteúdo único da página. Apenas um por página.
<article> Artigo independente Post de blog, notícia, comentário, produto
<section> Secção temática Grupo de conteúdo relacionado com um tema
<aside> Conteúdo lateral Sidebar, caixa de info, publicidade, links relacionados
<footer> Rodapé Direitos de autor, contactos, links úteis
<figure> Figura com legenda Imagem, gráfico, código com <figcaption>
<time> Data/hora <time datetime="2024-03-15">15 de março</time>
<mark> Texto destacado Resultado de pesquisa, texto importante
article vs. section Usa <article> para conteúdo que faz sentido sozinho fora da página (podias copiar para outro site e fazia sentido). Usa <section> para agrupar conteúdo relacionado que faz parte de um todo maior.

2.3 Layout típico de uma página

Estrutura de uma página de blog/notícias típica:

<!DOCTYPE html>
<html lang="pt">
<head>
  <meta charset="UTF-8">
  <title>O Meu Blog</title>
</head>
<body>

  <header>
    <h1>O Meu Blog</h1>
    <p>Textos sobre tecnologia e cultura</p>
  </header>

  <nav>
    <a href="index.html">Início</a>
    <a href="sobre.html">Sobre</a>
    <a href="contacto.html">Contacto</a>
  </nav>

  <main>

    <article>
      <h2>Título do Artigo</h2>
      <p><time datetime="2024-11-01">1 de novembro de 2024</time></p>
      <p>Texto do artigo...</p>
    </article>

    <article>
      <h2>Outro Artigo</h2>
      <p>Mais texto...</p>
    </article>

  </main>

  <aside>
    <h2>Artigos Recentes</h2>
    <!-- lista de links -->
  </aside>

  <footer>
    <p>&copy; 2024 O Meu Blog</p>
  </footer>

</body>
</html>
Entidade &copy; O símbolo © escreve-se em HTML como &copy;. Outras entidades úteis: &amp; (&), &lt; (<), &gt; (>), &nbsp; (espaço sem quebra de linha).

2.4 Elementos de bloco vs. elementos inline

Os elementos HTML dividem-se em dois grandes grupos:

TipoComportamentoExemplos
Bloco Ocupa toda a largura disponível. Começa numa nova linha. h1–h6, p, div, header, section, ul, li
Inline Ocupa apenas o espaço do seu conteúdo. Flui dentro do texto. a, strong, em, span, img, code 
<p>
  Este é um parágrafo com
  <strong>texto a negrito</strong> e
  <em>texto em itálico</em> dentro da mesma linha.
</p>

<!-- ERRADO: não podes pôr um bloco dentro de um inline -->
<span><p>Isto está errado!</p></span>

<!-- CORRETO: inline dentro de bloco -->
<p><span>Isto está correto.</span></p>

2.5 div e span — os contenores genéricos

Quando nenhum elemento semântico se aplica, usa os contenores genéricos:

  • <div> — contentor de bloco genérico, para agrupar elementos.
  • <span> — contentor inline genérico, para marcar partes de texto.
<!-- div para agrupar elementos com o mesmo estilo/função -->
<div class="cartao">
  <h3>João Silva</h3>
  <p>Estudante de Informática</p>
</div>

<!-- span para estilizar parte de um texto -->
<p>
  O preço é <span class="preco">29,99€</span>.
</p>
Regra prática Antes de usares <div>, pergunta: "existe um elemento semântico que descreve melhor isto?" Se sim, usa-o. O <div> deve ser o último recurso, não o primeiro.

2.6 Atributos id e class em detalhe

O atributo id

  • Identifica um único elemento na página.
  • Não pode haver dois elementos com o mesmo id.
  • Usado para: âncoras (#secao1), CSS específico, manipulação com JavaScript.

O atributo class

  • Pode ser usada em múltiplos elementos.
  • Um elemento pode ter múltiplas classes separadas por espaço.
  • Usado principalmente para aplicar estilos CSS.
<!-- id único por página -->
<section id="sobre-nos">...</section>

<!-- class reutilizável -->
<p class="destaque">Texto 1</p>
<p class="destaque">Texto 2</p>

<!-- múltiplas classes no mesmo elemento -->
<button class="btn btn-primario btn-grande">Enviar</button>
