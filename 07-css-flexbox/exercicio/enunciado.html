Ficha 07 — Layout Flexbox

Navbar, galeria de cards e footer com colunas

Objetivos

  • Criar uma navbar horizontal com Flexbox
  • Criar uma galeria de cards responsiva com flex-wrap
  • Usar justify-content e align-items para posicionamento
  • Usar flex: 1 para distribuição de espaço
  • Criar um footer com colunas usando Flexbox

Enunciado

Cria um site de portfolio chamado portfolio.html com css/portfolio.css.

Componentes a construir com Flexbox

1. Navbar

  • Logo à esquerda, links de navegação à direita.
  • justify-content: space-between; align-items: center;
  • Os links de nav são uma lista <ul> também em Flexbox com gap.

2. Hero

  • Flexbox em coluna (flex-direction: column) para centrar verticalmente.
  • min-height: 80vh; justify-content: center; align-items: center;

3. Galeria de Projetos (6 cards)

  • Container: display: flex; flex-wrap: wrap; gap: 1.5rem;
  • Cada card: flex: 1 1 280px; (mínimo 280px, cresce igualmente)
  • Cada card é também um flex container em coluna, com o botão "Ver projeto" no fundo (usando margin-top: auto).

4. Footer com 3 colunas

  • Container: display: flex; justify-content: space-between; flex-wrap: wrap;
  • Cada coluna: flex: 1 1 200px;
  • Colunas: "Sobre", "Navegação" (lista de links), "Contacto".
Dica: botão no fundo do card Para empurrar o botão para o fundo do card, independentemente do tamanho do texto: 
.card { display: flex; flex-direction: column; }
.card .btn { margin-top: auto; }
