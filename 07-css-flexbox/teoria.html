7.1 Conceito de Flexbox

Flexbox (Flexible Box Layout) é um modelo de layout CSS concebido para distribuir elementos a uma dimensão — numa linha ou numa coluna — com controlo preciso sobre alinhamento e distribuição de espaço.

Funciona com dois tipos de elementos:

  • Flex container — o elemento pai com display: flex
  • Flex items — os filhos diretos do container
<!-- HTML -->
<div class="container">        <!-- flex container -->
  <div class="item">A</div>  <!-- flex item -->
  <div class="item">B</div>
  <div class="item">C</div>
</div>
/* CSS */
.container {
  display: flex;
}

7.3 flex-direction e os eixos

O Flexbox trabalha com dois eixos perpendiculares:

  • Eixo principal — a direção dos flex items (definido por flex-direction)
  • Eixo cruzado — perpendicular ao eixo principal
.container {
  display: flex;

  /* → em linha (padrão) */
  flex-direction: row;

  /* ↓ em coluna */
  flex-direction: column;

  /* ← linha invertida */
  flex-direction: row-reverse;

  /* ↑ coluna invertida */
  flex-direction: column-reverse;
}
Atenção ao eixo! justify-content alinha no eixo principal e align-items alinha no eixo cruzado. Quando mudas o flex-direction para column, os eixos trocam!

7.4 justify-content

Distribui os items no eixo principal:

.container {
  display: flex;

  /* [A B C      ] items no início (padrão) */
  justify-content: flex-start;

  /* [   A B C   ] items no centro */
  justify-content: center;

  /* [      A B C] items no fim */
  justify-content: flex-end;

  /* [A    B    C] espaço entre items */
  justify-content: space-between;

  /* [ A   B   C ] espaço à volta de cada item */
  justify-content: space-around;

  /* [  A  B  C  ] espaço igual entre todos */
  justify-content: space-evenly;
}

7.5 align-items e align-content

.container {
  display: flex;
  height: 200px;   /* precisa de altura para ver efeito */

  /* items esticados para preencher (padrão) */
  align-items: stretch;

  /* items no topo do eixo cruzado */
  align-items: flex-start;

  /* items centrados verticalmente */
  align-items: center;

  /* items na base */
  align-items: flex-end;

  /* alinhados pela linha de base do texto */
  align-items: baseline;
}

/* Centrar perfeito — horizontal E vertical */
.centrado {
  display: flex;
  justify-content: center;
  align-items: center;
}

7.6 flex-wrap

Por padrão, os flex items tentam caber todos numa linha. Com flex-wrap permites que quebrem para nova linha:

.galeria {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

.galeria .foto {
  width: 200px;
  height: 150px;
}

7.7 Propriedades dos flex items

.item {
  /* flex-grow: quanto cresce relativamente (padrão: 0) */
  flex-grow: 1;   /* preenche espaço disponível */

  /* flex-shrink: quanto encolhe se necessário (padrão: 1) */
  flex-shrink: 0;  /* não encolhe */

  /* flex-basis: tamanho inicial (padrão: auto) */
  flex-basis: 200px;

  /* Atalho: flex: grow shrink basis */
  flex: 1 1 200px;
  flex: 1;           /* = flex: 1 1 0 */

  /* Sobrepor o align-items do container */
  align-self: flex-end;

  /* Ordem de exibição (padrão: 0) */
  order: -1;  /* aparece primeiro */
}

7.8 Exemplos práticos

Barra de navegação

/* HTML */
<nav class="navbar">
  <a href="#" class="logo">Site</a>
  <ul class="links">
    <li><a href="#">Início</a></li>
    <li><a href="#">Sobre</a></li>
    <li><a href="#">Contacto</a></li>
  </ul>
</nav>
/* CSS */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
}

.links {
  display: flex;
  list-style: none;
  gap: 2rem;
}

Cards responsivos

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
}

.card {
  flex: 1 1 280px;  /* mínimo 280px, cresce igualmente */
  padding: 1.5rem;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}

Footer com colunas

footer {
  display: flex;
  justify-content: space-between;
  flex-wrap: wrap;
  gap: 2rem;
}

footer .coluna {
  flex: 1 1 200px;
}
