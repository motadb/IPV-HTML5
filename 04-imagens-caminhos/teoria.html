4.1 O elemento <img>

O elemento <img> é um elemento vazio (sem tag de fecho) que insere uma imagem na página. Os dois atributos obrigatórios são src e alt. 

<!-- Sintaxe básica -->
<img src="imagens/foto.jpg" alt="Descrição da imagem">

<!-- Com dimensões definidas -->
<img src="imagens/logo.png"
     alt="Logótipo da empresa"
     width="200"
     height="80">

<!-- Imagem com link -->
<a href="index.html">
  <img src="imagens/logo.png" alt="Início">
</a>

4.2 O atributo alt

O atributo alt (alternative text) é obrigatório em todas as imagens. Serve para:

  • Acessibilidade: é lido pelos leitores de ecrã para pessoas invisuais.
  • SEO: motores de busca usam-no para indexar a imagem.
  • Fallback: é exibido se a imagem não carregar.
<!-- BOAS práticas de alt -->

<!-- Imagem informativa: descreve o conteúdo -->
<img src="grafico-vendas.png" alt="Gráfico de barras mostrando aumento de 30% nas vendas em 2024">

<!-- Imagem decorativa: alt vazio (sem espaço!) -->
<img src="separador-decorativo.png" alt="">

<!-- Ícone funcional: descreve a função -->
<img src="icone-pesquisa.svg" alt="Pesquisar">
Nunca escrevas "imagem de..." no alt O leitor de ecrã já anuncia que é uma imagem. Escreve a descrição diretamente: ✗ alt="Imagem de um gato" → ✓ alt="Gato laranja a dormir numa cadeira"

4.3 Dimensões e CSS

Os atributos width e height em HTML definem as dimensões em píxeis. Recomenda-se sempre defini-los para evitar layout shift (a página a "saltar" enquanto as imagens carregam).

Para controlo total do tamanho, usa CSS — é mais flexível: 

<!-- HTML: define as proporções originais -->
<img src="foto.jpg" alt="..." width="800" height="600">
/* CSS: controla o tamanho real na página */
img {
  max-width: 100%;   /* nunca ultrapassa o contentor */
  height: auto;       /* mantém proporções */
}

4.4 Formatos de imagem para a web

FormatoExtensãoTransparênciaQuando usar
JPEG .jpg / .jpeg Não Fotografias e imagens com muitas cores. Compressão com perdas.
PNG .png Sim Logos, ícones, gráficos com poucas cores. Sem perdas.
GIF .gif Sim (1-bit) Animações simples. Máx. 256 cores.
SVG .svg Sim Vetorial: logos, ícones, ilustrações. Escala sem perda de qualidade.
WebP .webp Sim Formato moderno. Melhor compressão que JPEG/PNG. Recomendado.
Regra prática Fotografias → JPEG ou WebP | Logos/ícones → SVG ou PNG | Animações → GIF (ou vídeo MP4)

4.5 Organização de ficheiros — boas práticas

Mantém o projeto organizado com uma estrutura clara de pastas:

meu-site/
├── index.html
├── sobre.html
├── css/
│   └── estilo.css
├── imagens/
│   ├── logo.svg
│   ├── hero.jpg
│   └── galeria/
│       ├── foto1.jpg
│       ├── foto2.jpg
│       └── foto3.jpg
└── documentos/
    └── brochura.pdf
Convenções de nomenclatura Usa sempre minúsculas nos nomes de ficheiros e pastas. Substitui espaços por hífens: foto-da-turma.jpg, não Foto da Turma.jpg. Servidores web Linux são sensíveis a maiúsculas/minúsculas (case-sensitive).

Como referenciar as imagens

<!-- Em index.html (raiz) -->
<img src="imagens/logo.svg" alt="Logo">
<img src="imagens/galeria/foto1.jpg" alt="Foto 1 da galeria">

<!-- Em páginas/contacto.html (numa subpasta) -->
<img src="../imagens/logo.svg" alt="Logo">
<img src="../imagens/galeria/foto1.jpg" alt="Foto 1">

4.6 figure e figcaption

O elemento <figure> agrupa uma imagem com a sua legenda (<figcaption>). É o uso semântico correto para imagens com legenda. 

<figure>
  <img src="imagens/castelo.jpg"
       alt="Vista aérea do Castelo de Viseu ao pôr do sol"
       width="800" height="500">
  <figcaption>Vista aérea do Castelo de Viseu. Foto: João Costa, 2024.</figcaption>
</figure>

O <figure> não precisa de ser sempre uma imagem — pode ser um gráfico, código, vídeo ou qualquer conteúdo auto-contido com legenda: 

<figure>
  <pre><code>console.log("Olá mundo");</code></pre>
  <figcaption>Exemplo de código JavaScript para imprimir no console.</figcaption>
</figure>

4.7 Imagem responsiva

Para servir imagens diferentes consoante o tamanho do ecrã, usa srcset: 

<!-- O browser escolhe a imagem mais adequada -->
<img
  src="foto-800.jpg"
  srcset="foto-400.jpg 400w,
          foto-800.jpg 800w,
          foto-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Paisagem da Serra da Estrela">
Nota srcset e sizes são avançados para quem começa. O mais importante agora é usar max-width: 100% em CSS para que as imagens não transbordem o seu contentor em ecrãs pequenos.
