Ficha 04 — Galeria de Imagens

Imagens, caminhos relativos e figure/figcaption

Objetivos

  • Organizar ficheiros de imagem em pastas com nomes corretos
  • Inserir imagens com src usando caminhos relativos corretos
  • Escrever atributos alt descritivos e adequados
  • Usar figure e figcaption para imagens com legenda
  • Criar uma imagem que funcione como link

Enunciado

Cria uma galeria de fotografias sobre um tema à tua escolha (natureza, arquitetura, animais, desporto, etc.).

Estrutura de ficheiros obrigatória

galeria/
├── index.html
├── sobre.html
└── imagens/
    ├── logo.png       (cria um ficheiro de texto com este nome — vê nota)
    ├── destaque.jpg
    └── galeria/
        ├── foto1.jpg
        ├── foto2.jpg
        ├── foto3.jpg
        └── foto4.jpg
Nota sobre imagens reais Podes usar imagens reais que tenhas disponíveis, ou usar imagens placeholder: <img src="https://picsum.photos/400/300" alt="Foto aleatória"> (Picsum Photos fornece imagens de placeholder gratuitas)

Página index.html

  • Logo no topo — imagem imagens/logo.png que funciona como link para index.html. Alt: "Logo da galeria".
  • Título h1 da galeria.
  • Parágrafo de descrição.
  • Imagem de destaque usando <figure> + <figcaption>. Dimensões: 800x400.
  • Secção de galeria com 4 imagens em <figure>, cada uma com legenda. Dimensões: 300x200 cada.
  • Link para sobre.html.

Página sobre.html

  • Navegação com link de volta ao índice usando caminho relativo.
  • Logo no topo usando o caminho correto (imagens/logo.png).
  • Título h1 "Sobre esta galeria".
  • Parágrafo sobre o tema das fotos.
Dica sobre caminhos Tanto no index.html como no sobre.html (que estão no mesmo nível), o caminho para as imagens começa por imagens/. O caminho ../imagens/ seria necessário se os HTML estivessem numa subpasta.
