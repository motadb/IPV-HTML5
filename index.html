Bem-vindo ao Manual

Este manual foi criado para te guiar desde o zero absoluto até conseguires construir páginas web com estrutura semântica, estilização profissional e formulários funcionais. Não é necessário nenhum conhecimento prévio de programação.

Cada capítulo tem uma parte teórica com exemplos de código explicados e uma ficha de exercícios com enunciado, esqueleto de arranque e solução.

Como usar este manual Lê a teoria, experimenta os exemplos no teu editor, e depois resolve a ficha de exercícios sem ver a solução. Consulta só a solução depois de tentares!

Ferramentas Necessárias

Para acompanhar este manual precisas apenas de:

  • Editor de código: Visual Studio Code (recomendado) — instala a extensão Live Server para ver as alterações em tempo real.
  • Browser: Google Chrome ou Firefox com as ferramentas de programador abertas com F12.
Nota Não precisas de servidor, internet ou instalar nada especial. Os ficheiros HTML abrem diretamente no browser — basta fazer duplo clique ou arrastar para o browser.
