Ficha 05 — Estilizar uma Página

CSS: seletores, cores e tipografia

Objetivos

  • Criar e ligar um ficheiro CSS externo
  • Usar seletores de elemento, classe e id
  • Aplicar cores em formatos hexadecimal e rgba
  • Controlar tipografia: família, tamanho, peso e alinhamento
  • Usar pseudo-classes :hover e :first-child

Enunciado

Pega na página noticias.html que criaste na Ficha 02 (ou no ficheiro de solução desta ficha) e cria um ficheiro CSS externo chamado estilos.css para a estilizar.

Ficheiros necessários

ficha05/
├── noticias.html   (reutiliza a solução da ficha 02)
└── css/
    └── estilos.css (crias agora)

Requisitos do CSS

O ficheiro estilos.css deve conter:

Elemento/SeletorEstilos a aplicar
body Cor de fundo (#f5f5f5), família tipográfica (sans-serif), tamanho 16px, cor do texto (#333)
header Cor de fundo azul escuro (#1a3a5c), cor do texto branco, padding 2rem, text-align center
header h1 Font-size 2.5rem, font-weight 700, margin-bottom 0.5rem
nav Cor de fundo #2563eb, padding 1rem 2rem
nav a Cor branca, sem sublinhado (text-decoration: none), padding 0.5rem 1rem
nav a:hover Cor de fundo rgba(255,255,255,0.2), border-radius 4px
main max-width 900px, margin 2rem auto, padding 0 1rem
article Cor de fundo branca, padding 1.5rem, margin-bottom 1.5rem, border-radius 8px, border-left 4px solid #2563eb
article h2 Cor #1a3a5c, font-size 1.4rem
article:first-child border-left-color #f59e0b (amarelo — destaque)
aside Cor de fundo #eff6ff, padding 1.5rem, border-radius 8px
footer Cor de fundo #1a3a5c, cor do texto #94a3b8, text-align center, padding 1.5rem, margin-top 2rem
Boa prática Começa por escrever o reset: * { box-sizing: border-box; margin: 0; padding: 0; } Esta regra garante que todos os elementos partem de zero e que o box model é previsível.
