5.1 O que é CSS?

CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata). Define a apresentação visual de um documento HTML: cores, tipografia, espaçamentos, dimensões, posicionamento e muito mais.

O conceito de cascata refere-se ao facto de múltiplas regras CSS poderem aplicar-se ao mesmo elemento, com regras específicas para decidir qual prevalece.

5.2 Formas de aplicar CSS

1. CSS Externo (recomendado)

Num ficheiro .css separado, ligado no <head>:

<!-- No <head> do HTML -->
<link rel="stylesheet" href="css/estilo.css">
/* estilo.css */
body {
  font-family: Arial, sans-serif;
  color: #333;
}

2. CSS Interno

Numa tag <style> dentro do <head>:

<head>
  <style>
    p { color: blue; }
  </style>
</head>

3. CSS Inline (evitar)

Diretamente no atributo style do elemento:

<p style="color: blue; font-size: 18px;">Texto azul</p>
Usa sempre CSS externo O CSS externo separa a estrutura (HTML) da apresentação (CSS), facilita a manutenção e permite reutilizar o mesmo estilo em múltiplas páginas. CSS inline dificulta a manutenção e tem prioridade máxima, tornando difícil sobrescrever.

5.3 Sintaxe CSS

seletor {
  propriedade: valor;
  outra-propriedade: outro-valor;
}
h1 {
  color: #2563eb;
  font-size: 2rem;
  font-weight: 700;
  margin-bottom: 1rem;
}

p {
  line-height: 1.6;
  color: #333;
}

/* Múltiplos seletores com a mesma regra */
h1, h2, h3 {
  font-family: Georgia, serif;
}

5.5 Especificidade e cascata

Quando várias regras CSS se aplicam ao mesmo elemento, a especificidade determina qual prevalece. Regra geral — do mais específico para o menos:

  1. CSS inline (style="...") — especificidade máxima
  2. Seletores de ID (#id)
  3. Seletores de classe, atributo e pseudo-classe (.classe)
  4. Seletores de elemento e pseudo-elemento (p)

Se a especificidade for igual, vence a regra que vem por último no código.

p         { color: black; }    /* especificidade: 1 */
.intro    { color: blue;  }    /* especificidade: 10 */
#destaque { color: red;   }    /* especificidade: 100 */

/* Este parágrafo fica vermelho: */
<p id="destaque" class="intro">Texto</p>
Boas práticas Evita usar !important (que sobrescreve tudo) — é um sinal de que a arquitetura CSS está mal estruturada. Prefere seletores de classe e mantém a especificidade baixa e consistente.

5.7 Tipografia

body {
  /* Família tipográfica (lista de fallbacks) */
  font-family: 'Segoe UI', Arial, sans-serif;

  /* Tamanho */
  font-size: 16px;

  /* Espessura: 100–900, normal=400, bold=700 */
  font-weight: 400;

  /* Estilo: normal, italic, oblique */
  font-style: normal;

  /* Altura da linha (sem unidade = relativo ao font-size) */
  line-height: 1.6;
}

h1 {
  font-size: 2.5rem;
  font-weight: 700;
  letter-spacing: -0.02em;  /* espaçamento entre letras */
}

p {
  text-align: left;        /* left | center | right | justify */
  text-decoration: none;  /* none | underline | line-through */
  text-transform: none;   /* none | uppercase | lowercase | capitalize */
}

Google Fonts

Para usar fontes externas, adiciona no <head> antes do teu CSS:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap"
      rel="stylesheet">
body {
  font-family: 'Inter', sans-serif;
}
