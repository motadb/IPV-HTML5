Ficha 09 — Formulário de Inscrição

Todos os tipos de input, validação e acessibilidade

Objetivos

  • Criar um formulário completo com fieldsets agrupados
  • Usar pelo menos 8 tipos diferentes de input
  • Associar corretamente todos os labels com for/id
  • Aplicar atributos de validação HTML5 (required, pattern, min/max)
  • Estilizar o formulário com CSS para aspeto profissional

Enunciado

Cria um formulário de inscrição nas Jornadas de Informática 2026 do IPV. O ficheiro chama-se inscricao.html com CSS em css/form.css.

Botões

  • Botão "Submeter inscrição" (type="submit")
  • Botão "Limpar formulário" (type="reset")

CSS do formulário

  • Cada grupo label + input deve ser um <div class="campo"> com display: flex; flex-direction: column; gap: 0.25rem;
  • Os inputs têm: padding 0.5rem, border 1px solid #ccc, border-radius 4px, width 100%
  • Ao focar (:focus): outline none, border-color #2563eb, box-shadow azul claro
  • Labels: font-weight 600, font-size 0.9rem
  • Fieldsets: padding 1.5rem, border 1px solid #e2e8f0, border-radius 8px, margin-bottom 1.5rem
  • Legends: color #2563eb, font-weight 700
