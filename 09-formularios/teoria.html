9.1 O elemento <form>

O <form> agrupa todos os controlos de um formulário e define para onde e como os dados são enviados. 

<form action="processar.php" method="post">
  <!-- campos do formulário -->
</form>
AtributoValoresDescrição
action URL Para onde os dados são enviados ao submeter. Omitindo, envia para a página atual.
method get / post GET: dados na URL (pesquisas). POST: dados no corpo do pedido (dados sensíveis, ficheiros).
enctype multipart/form-data Obrigatório para upload de ficheiros.
novalidate — Desativa a validação nativa do browser.
autocomplete on / off Ativa/desativa preenchimento automático.

9.2 label e input — a ligação essencial

O <label> descreve o campo e deve estar sempre associado ao input correspondente. Melhora drasticamente a usabilidade e acessibilidade: clicar no label foca o campo. 

<!-- Método 1: for + id (recomendado) -->
<label for="nome">Nome completo</label>
<input type="text" id="nome" name="nome">

<!-- Método 2: label envolve o input -->
<label>
  Email
  <input type="email" name="email">
</label>
O atributo name é obrigatório! O name identifica o campo quando os dados são enviados para o servidor. Sem ele, o campo não é incluído na submissão do formulário.

9.3 Tipos de input

typeAparência / Comportamento
textCampo de texto de uma linha (por defeito)
emailValida formato de email. Teclado adaptado em mobile.
passwordEsconde os caracteres com •
numberAceita apenas números. Setas para incrementar.
telTeclado numérico em mobile. Sem validação automática.
urlValida formato de URL.
dateSeletor de data nativo do browser.
timeSeletor de hora.
datetime-localSeletor de data e hora.
checkboxCaixa de seleção (múltiplas opções).
radioBotão de opção (escolha exclusiva no grupo).
rangeSlider entre min e max.
colorSeletor de cor.
fileUpload de ficheiro.
hiddenInvisível ao utilizador. Envia valores fixos.
searchCampo de pesquisa (com botão de limpar).
submitBotão de submissão.
resetBotão que limpa o formulário.
 
<!-- Checkbox -->
<input type="checkbox" id="newsletter" name="newsletter">
<label for="newsletter">Subscrever newsletter</label>

<!-- Radio buttons (mesmo name = grupo exclusivo) -->
<p>Género:</p>
<input type="radio" id="masc" name="genero" value="M">
<label for="masc">Masculino</label>
<input type="radio" id="fem"  name="genero" value="F">
<label for="fem">Feminino</label>

<!-- Range -->
<label for="satisfacao">Satisfação (1–10):</label>
<input type="range" id="satisfacao" name="satisfacao"
       min="1" max="10" value="5">

<!-- Upload de ficheiro -->
<input type="file" name="foto" accept="image/*">

9.4 textarea e select

textarea — texto longo

<label for="mensagem">Mensagem</label>
<textarea id="mensagem" name="mensagem"
           rows="5" cols="40"
           placeholder="Escreve a tua mensagem aqui..."
           maxlength="500"></textarea>

select — lista de opções

<label for="pais">País</label>
<select id="pais" name="pais" required>
  <option value="">-- Seleciona --</option>
  <optgroup label="Europa">
    <option value="pt">Portugal</option>
    <option value="es">Espanha</option>
    <option value="fr">França</option>
  </optgroup>
  <optgroup label="América">
    <option value="br">Brasil</option>
  </optgroup>
</select>

<!-- Seleção múltipla -->
<select name="interesses" multiple size="4">
  <option value="html">HTML/CSS</option>
  <option value="js">JavaScript</option>
</select>

9.5 fieldset e legend

<fieldset> agrupa campos relacionados. <legend> é o título do grupo. Essencial para acessibilidade. 

<fieldset>
  <legend>Dados Pessoais</legend>

  <label for="nome">Nome</label>
  <input type="text" id="nome" name="nome">

  <label for="email">Email</label>
  <input type="email" id="email" name="email">
</fieldset>

<fieldset>
  <legend>Preferências</legend>
  <!-- campos de preferências -->
</fieldset>

9.6 Validação HTML5

O HTML5 inclui validação nativa — o browser verifica os campos antes de submeter o formulário, sem precisar de JavaScript.

AtributoAplica-se aEfeito
requiredQualquer campoObrigatório — não permite submeter vazio.
minnumber, date, rangeValor mínimo.
maxnumber, date, rangeValor máximo.
minlengthtext, email, etc.Mínimo de caracteres.
maxlengthtext, email, etc.Máximo de caracteres.
patterntext, email, etc.Expressão regular que o valor deve seguir.
placeholderQualquer campo de textoTexto de dica (desaparece ao escrever).
autocompleteQualquer campoon/off — preenchimento automático.
autofocusQualquer campoFoca este campo ao carregar a página.
disabledQualquer campoCampo inativo — não é enviado.
readonlyQualquer campoApenas leitura — é enviado.
multipleemail, file, selectAceita múltiplos valores.
 
<input type="text"
       name="username"
       required
       minlength="3"
       maxlength="20"
       pattern="[a-zA-Z0-9_]+"
       placeholder="3 a 20 letras, números ou _"
       autocomplete="username">

<input type="number"
       name="idade"
       min="18"
       max="120"
       required>

9.7 O elemento button

<!-- Submete o formulário (por defeito num form) -->
<button type="submit">Enviar</button>

<!-- Limpa o formulário -->
<button type="reset">Limpar</button>

<!-- Botão genérico (não submete, para JavaScript) -->
<button type="button">Ação</button>

<!-- Button vs input type="submit":
     button permite HTML dentro (ícones, spans)
     input type="submit" só permite texto simples -->
<button type="submit">
  Enviar →
</button>

9.8 Formulário completo — Exemplo

<form action="#" method="post">

  <fieldset>
    <legend>Dados Pessoais</legend>

    <label for="nome">Nome *</label>
    <input type="text" id="nome" name="nome"
           required minlength="2"
           placeholder="O teu nome"
           autocomplete="name" autofocus>

    <label for="email">Email *</label>
    <input type="email" id="email" name="email"
           required placeholder="exemplo@email.com"
           autocomplete="email">

    <label for="tel">Telefone</label>
    <input type="tel" id="tel" name="telefone"
           pattern="[0-9]{9}"
           placeholder="9 dígitos">
  </fieldset>

  <fieldset>
    <legend>Mensagem</legend>

    <label for="assunto">Assunto *</label>
    <select id="assunto" name="assunto" required>
      <option value="">-- Seleciona --</option>
      <option value="info">Informação</option>
      <option value="suporte">Suporte</option>
    </select>

    <label for="mensagem">Mensagem *</label>
    <textarea id="mensagem" name="mensagem"
              rows="5" required
              minlength="10" maxlength="500"
              placeholder="Descreve o assunto..."></textarea>
  </fieldset>

  <div>
    <input type="checkbox" id="aceito" name="aceito" required>
    <label for="aceito">Aceito os termos e condições *</label>
  </div>

  <button type="submit">Enviar Mensagem</button>
  <button type="reset">Limpar</button>

</form>
